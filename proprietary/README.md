# Proprietary component inventory

This directory is for documentation about proprietary dependencies, not for storing proprietary binaries.

For each component, record its name, originating device/build, purpose, dependencies, source or acquisition reference, license terms, redistribution permission and compatibility status.

Do not commit restricted Samsung or Motorola APKs, libraries, firmware, vendor blobs, private keys or other non-redistributable material. A component being publicly downloadable does not automatically mean it may be redistributed.
