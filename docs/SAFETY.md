# Safety, provenance and publishing policy

## Protect the device

- Treat flashing and partition-writing as high risk.
- Do not test experimental builds on a primary-use phone.
- Confirm the exact XT2135-2 variant before using any device-specific image.
- Keep a verified stock restore package and recovery procedure available before testing.
- Do not publish instructions that encourage bypassing device security protections.

## Protect private information

Never commit passwords, access tokens, private signing keys, IMEI numbers, serial numbers, personal account data or unredacted diagnostic logs.

## Respect software licenses

- Do not upload Samsung or Motorola proprietary firmware, vendor images, proprietary applications or restricted binary blobs unless redistribution is explicitly permitted.
- Record the origin, version and license of every imported source or binary.
- Link to official sources where redistribution is not permitted.
- Keep original project code separate from third-party components.
- Do not imply Samsung or Motorola endorsement.

## Reporting test results

Include the exact device model, software versions, test steps, expected result, actual result and relevant redacted logs.

A successful compilation does not prove that a ROM boots. A successful boot does not prove that individual hardware features work. Publish only verified claims.
