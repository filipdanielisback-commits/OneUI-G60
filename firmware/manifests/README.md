# Firmware manifests

Create one text manifest per researched firmware package. Suggested fields:

- Manufacturer and reference device
- Model / region / CSC
- Firmware build identifier
- One UI and Android versions (with source)
- Release date
- Official source URL
- File names and sizes, if useful
- SHA-256 checksums, if lawfully obtained
- License and redistribution assessment
- Date checked and researcher notes

A manifest is metadata, not a firmware mirror. Never commit proprietary package contents.
