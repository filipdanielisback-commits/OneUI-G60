# Firmware research area

This directory stores documentation and metadata only.

Do not place proprietary Samsung or Motorola firmware archives, extracted images, vendor blobs, modem files, APKs, signing keys or other restricted binaries here unless redistribution is explicitly permitted.

Use `manifests/` for plain-text records of package identifiers, official source URLs, checksums where appropriate, version metadata and licensing status. Keep any locally obtained files outside the public repository and follow the applicable license and distribution terms.
