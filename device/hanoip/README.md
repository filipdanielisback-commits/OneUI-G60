# hanoip device research

This directory tracks device-specific research for the Motorola Moto G60 XT2135-2 and the shared hanoip platform references.

The shared codename is supported by community device-tree references, but configuration must be checked against the exact XT2135-2 regional variant and firmware.

Record:

- Upstream device-tree URL, branch and commit
- Exact model / SKU applicability
- Partition and boot metadata sources
- Vendor interface and VINTF findings
- Kernel and hardware dependencies
- Known differences between related hanoip devices

Do not copy a related device tree wholesale or treat historical / dropped community support as current build readiness.
